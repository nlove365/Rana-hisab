রানা হিসাব — প্রকল্প অবস্থা ও ব্যবহার নির্দেশিকা
সর্বশেষ সংশোধন: ২০২৬-১১-২১

বর্তমান অ্যাপের সুবিধা:
- বাংলা ভাষায় আয়, খরচ ও বিক্রয়/ক্রয় এন্ট্রি
- পণ্য তালিকা এবং পণ্যের একক: টি, কেজি, গ্রাম, লিটার, মিলিলিটারসহ
- গ্রামকে কেজি এবং মিলিলিটারকে লিটারে রূপান্তর করে স্টক গণনার ভিত্তি
- লেনদেন সম্পাদনা, সম্পাদনার পূর্বের তথ্যের audit history এবং Void (বাতিল) চিহ্ন
- POS কার্ট, ডিসকাউন্ট এবং বাকি হিসাবের প্রাথমিক সুবিধা
- তারিখভিত্তিক আয়-ব্যয়ের সারাংশ
- বাংলা টেক্সট কমান্ড; সমর্থিত ব্রাউজারে ভয়েস ইনপুট
- ছবি থেকে OCR (Tesseract.js CDN প্রয়োজন)
- JSON ব্যাকআপ ও রিস্টোর
- PWA অফলাইন ক্যাশ; নতুন সংস্করণে cache version পরিবর্তন করা হয়েছে
- অ্যাপের ভেতরে রানা হিসাব লোগো এবং স্বপ্নময় ইনক বিডির মালিকানা ঘোষণা

Android:
- GitHub Actions থেকে debug APK তৈরি হয়।
- Build workflow সর্বশেষ index.html, manifest, icon ও service worker Android assets-এ কপি করে।
- APK upload-এর আগে প্যাকেজের ভেতরে কপিরাইট লেখা ও icon asset আছে কি না যাচাই করে।
- Debug APK মানে এটি Play Store release signing করা production APK নয়।

ডেটা ও নিরাপত্তা:
- হিসাব, পণ্য ও পেমেন্ট বর্তমানে একই ডিভাইসের localStorage-এ থাকে।
- অ্যাপের ডেটা ক্লাউডে স্বয়ংক্রিয়ভাবে যায় না। ডিভাইস হারালে/অ্যাপের ডেটা মুছে গেলে ব্যাকআপ ছাড়া তথ্য হারাতে পারে।
- নিয়মিত JSON ব্যাকআপ নিন এবং অন্য নিরাপদ স্থানে রাখুন।
- Login, user roles/permissions, Firebase/cloud sync এখনো তৈরি হয়নি। নিরাপদভাবে চালু করতে সার্ভার/ব্যাকএন্ড, authentication এবং access rules প্রয়োজন; শুধু স্ক্রিনে login ফর্ম যোগ করলে নিরাপত্তা হবে না।

হিসাবের সীমা:
- POS ও রিপোর্ট প্রাথমিক পর্যায়ের। রিপোর্টে আয়-ব্যয়ের পার্থক্য দেখায়; প্রকৃত লাভের জন্য বিক্রীত পণ্যের ক্রয়মূল্য (COGS), স্টক valuation, কর/ভ্যাট, ফেরত ও অন্যান্য সমন্বয় দরকার।
- স্টক হিসাব পণ্যের লেনদেনের পরিমাণের ভিত্তিতে; আলাদা ব্যাচ, গুদাম, barcode, expiry বা stock valuation এখনো নেই।
- ভয়েস ইনপুট ব্রাউজার ও ফোনের সমর্থনের ওপর নির্ভরশীল।
- OCR ফলাফল সংরক্ষণের আগে মানুষকে যাচাই করতে হবে; বাংলা রসিদে ভুল পড়তে পারে।

PWA ইনস্টল:
1. HTTPS-এ হোস্ট করা ওয়েব অ্যাপ খুলুন।
2. Android Chrome-এর মেনু থেকে Install app / Add to Home screen নির্বাচন করুন।
3. শুধু ZIP ফাইল খুলে PWA ইনস্টল হয় না।
